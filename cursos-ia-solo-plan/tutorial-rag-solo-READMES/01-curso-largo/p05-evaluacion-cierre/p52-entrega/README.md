# P52 — Entrega y documentación

**Guía de proyecto · ~3 h**

## Qué construyes

README completo, ADR de todas las decisiones, reporte de métricas, dataset, demo funcional. Un tercero entiende cada parámetro.

## Contenidos

- README: arquitectura, setup, operación
- ADR: decisión, alternativas, reasoning
- Reporte: métricas finales, trade-offs elegidos
- Dataset: preguntas, respuestas, documentos
- Demo: script que muestra las cuatro preguntas de prueba
- Lista: limitaciones honestas

## Criterio de finalización

Un junior clona, ejecuta, lee la documentación. Entiende por qué cada parámetro vale lo que vale. Sin huecos de "porque sí".

## Después de esta guía

Pasás a P53. Ahora evoluciones posteriores.
