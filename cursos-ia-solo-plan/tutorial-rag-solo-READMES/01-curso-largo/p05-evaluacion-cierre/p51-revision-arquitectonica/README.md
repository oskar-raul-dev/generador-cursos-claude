# P51 — Revisión arquitectónica final

**Guía de proyecto · ~2 h**

## Qué construyes

Auditoría del sistema completo. Mantenibilidad, seguridad, rendimiento, trazabilidad.

## Contenidos

- Mantenibilidad: ¿cuánto cuesta cambiar X?
- Seguridad: ¿todos los riesgos están mitigados?
- Rendimiento: ¿el sistema es predecible?
- Trazabilidad: ¿se puede reconstruir cualquier decisión?
- Lista de deuda técnica conocida

## Criterio de finalización

Documento de revisión. Identifica fortalezas y debilidades. Ninguna sorpresa.

## Después de esta guía

Pasás a P52. Ahora documentación y entrega.
