# P50 — Pruebas de regresión

**Guía de proyecto · ~2 h**

## Qué construyes

Suite de pruebas que detecta degradación de calidad. Un cambio de configuración que empeora las métricas se flagea solo.

## Contenidos

- Script: corre dataset, compara contra baseline
- Threshold: qué degradación es tolerable
- CI/CD: pruebas corren automáticamente
- Revert automático si falla

## Criterio de finalización

Cambias un parámetro. Suite corre. Si empeora Hit Rate, el test falla. Cambio se revierte automáticamente.
