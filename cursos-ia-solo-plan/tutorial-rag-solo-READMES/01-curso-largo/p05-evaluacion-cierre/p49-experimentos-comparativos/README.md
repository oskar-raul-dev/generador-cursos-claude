# P49 — Experimentos comparativos

**Guía de proyecto · ~2.5 h**

## Qué construyes

Tabla de números reales. Varías: chunking, embeddings, topK, modo de recuperación, reranking. Mides Hit Rate, latencia, completitud.

## Contenidos

- Matriz de experimentos
- Para cada configuración: todas las métricas
- Gráficos: trade-off entre calidad y latencia
- Decisión: qué cambió por los números

## Criterio de finalización

Existe tabla con números verificables. Al menos una decisión cambió porque los números así lo exigieron (no porque "sí, estaría bueno").

## Después de esta guía

Pasás a P50. Ahora pruebas de regresión.
