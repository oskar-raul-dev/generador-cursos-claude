# P45 — Dataset de evaluación

**Guía de proyecto · ~2 h**

## Qué construyes

Preguntas reales, respuestas esperadas, documentos relevantes. Al menos 20% de los casos exige abstención.

## Contenidos

- Dataset: 50–100 preguntas
- Metadatos: documento relevante, fragmento esperado
- Preguntas con abstención: trampa de maternidad + otras
- Formato: JSON o CSV legible

## Criterio de finalización

Dataset existe. Contiene variedad: preguntas fáciles, difíciles, ambiguas, sin respuesta. Al menos 20% piden abstención.

## Después de esta guía

Pasás a P46. Ahora métricas de recuperación.
