# T11 — Generación fundamentada y citas

**Guía teórica · ~2 h**

## Qué aprenderás

Cómo construir prompts que obliguen al modelo a responder solo con lo recuperado. Cómo generar citas verificables. Cómo lograr que se abstenga.

## Contenidos

- Grounding: instrucciones explícitas para responder solo con la evidencia
- Citas: enlazar afirmaciones con su fuente
- Abstención: reconocer cuándo no hay suficiente información
- Construcción del prompt: estructura que ordena el modelo

## Criterio de finalización

Escribís un prompt que produce abstención de forma reproducible. Cambias un parámetro y el comportamiento cambia previsiblemente.

## Después de esta guía

Pasás a T12 sabiendo que el prompt es una pieza de diseño, no una improvisación.
