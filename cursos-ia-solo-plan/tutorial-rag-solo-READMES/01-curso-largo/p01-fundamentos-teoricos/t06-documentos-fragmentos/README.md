# T06 — Documentos, fragmentos y metadatos

**Guía teórica · ~2 h**

## Qué aprenderás

Cómo modelar documentos internamente. Qué metadatos preservar. Cómo la decisión sobre estructura impacta todo lo que viene después.

## Contenidos

- Documento: unidad de ingesta (archivo, texto, API)
- Fragmento: unidad de recuperación (porción de documento)
- Metadatos: fuente, versión, permisos, idioma, tenant, timestamp
- Trazabilidad: rastrear cualquier afirmación hasta su origen

## Criterio de finalización

Diseñás un modelo documental para un tipo de corpus concreto. Tu diseño soporta trazabilidad sin cambios posteriores.

## Después de esta guía

Pasás a T07 sabiendo exactamente qué metadatos necesitás para que el sistema funcione.
