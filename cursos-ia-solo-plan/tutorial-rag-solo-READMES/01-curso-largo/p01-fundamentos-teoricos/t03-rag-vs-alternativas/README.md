# T03 — RAG vs fine-tuning vs búsqueda tradicional

**Guía teórica · ~2 h**

## Qué aprenderás

Cuándo conviene RAG, cuándo fine-tuning, cuándo búsqueda tradicional. No son alternativas equivalentes; cada una resuelve un problema distinto.

## Contenidos

- RAG: recupera evidencia del dominio en tiempo de consulta
- Fine-tuning: adapta el modelo con datos del dominio
- Búsqueda tradicional: indexación por palabras clave
- Criterios para elegir cada uno

## Criterio de finalización

Argumentás con un caso concreto cuándo conviene RAG y cuándo fine-tuning. Tu argumento distingue entre "necesito que el modelo conozca X" y "necesito respuestas basadas en X".

## Después de esta guía

Pasás a T04 con convicción de que RAG es la herramienta correcta para el problema que vas a resolver.
