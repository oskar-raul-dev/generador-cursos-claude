# T02 — Conocimiento paramétrico y alucinación

**Guía teórica · ~2 h**

## Qué aprenderás

Qué significa que un modelo "sepa" algo, y por qué inventa con confianza cuando no sabe. La diferencia entre conocimiento paramétrico (aprendido durante entrenamiento) y conocimiento contextual (en el prompt).

## Contenidos

- Conocimiento paramétrico: lo que el modelo aprendió durante entrenamiento
- Alucinación: por qué el modelo genera respuestas falsas con confianza
- Ventana de contexto: cómo entra información nueva sin reentrenamiento
- El problema que RAG resuelve explícitamente

## Criterio de finalización

Explicás qué significa que un modelo "sepa" algo y por qué la confianza de una respuesta falsa no es indicador de verdad.

## Después de esta guía

Pasás a T03 con claridad sobre por qué un LLM necesita RAG para conocimientos específicos del dominio.
