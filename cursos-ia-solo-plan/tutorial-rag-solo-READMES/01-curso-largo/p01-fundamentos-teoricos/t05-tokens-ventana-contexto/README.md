# T05 — Tokens, ventana de contexto y presupuesto

**Guía teórica · ~2 h**

## Qué aprenderás

Cómo contar tokens, cómo medir la ventana de contexto, cómo presupuestar espacio entre instrucciones, historial y evidencia. Este es el constraint más concreto de RAG.

## Contenidos

- Qué es un token y por qué no es una palabra
- Ventana de contexto: límite de tokens que el modelo acepta
- Presupuesto de tokens: instrucciones + historial + evidencia + respuesta
- Cálculos prácticos para tu corpus

## Criterio de finalización

Calculás cuánta evidencia cabe en una ventana dada. Tu cálculo contempla espacio para instrucciones, respuesta esperada e historial si hay conversación.

## Después de esta guía

Pasás a T06 sabiendo exactamente cuánto peso tienes disponible para recuperar.
