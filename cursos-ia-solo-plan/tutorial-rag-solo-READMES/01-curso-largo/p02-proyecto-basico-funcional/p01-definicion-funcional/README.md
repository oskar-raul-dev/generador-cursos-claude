# P01 — Definición funcional

**Guía de proyecto · ~3 h**

## Qué construyes

La especificación del proyecto completo. Casos de uso, actores, documentos de entrada, preguntas que el sistema debe responder y, crucialmente, alcance del MVP: qué queda fuera.

## Contenidos

- Casos de uso: quién pregunta qué
- Documentos de entrada: tipos, volumen, estructura
- Conjunto inicial de preguntas de prueba
- Alcance explícito del MVP
- Supuestos y restricciones

## Criterio de finalización

El alcance está escrito. Dice explícitamente qué queda fuera (multitenancy, multiidioma, conversación, etc.). Pasás a P02 sin ambigüedad sobre qué construyes.

## Después de esta guía

Pasás a P02 con especificación clara. Cada decisión arquitectónica en P02 se ancla en algo que escribiste acá.
