# P16 — Citas y trazabilidad

**Guía de proyecto · ~2.5 h**

## Qué construyes

Cada afirmación en la respuesta se enlaza con su fuente. Formato: "[Fuente]" o "[1]" + lista de fuentes al final.

## Contenidos

- CitationExtractor: detecta citas del LLM
- SourceMapper: conecta citas con fragmentos originales
- Respuesta con citas: texto + referencias
- Verificación: toda afirmación tiene fuente identificable

## Criterio de finalización

Una respuesta tiene citas verificables. Click en una cita te lleva al documento y fragmento originales.

## Después de esta guía

Pasás a P17. El sistema ahora responde y cita. Falta que se abstenga.
