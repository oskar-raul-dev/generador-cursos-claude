# P02 — Arquitectura y decisiones técnicas

**Guía de proyecto · ~2.5 h**

## Qué construyes

La especificación técnica del sistema. Decisiones fundamentales registradas como ADR (Architecture Decision Record). Para cada decisión: alternativas consideradas y por qué se descartaron.

## Contenidos

- Selección de tecnologías (por qué Spring AI y no LangChain)
- Modelo de datos preliminar
- Estrategia de vectorización
- Estrategia de almacenamiento
- API externa vs interna
- ADR: formato de decisión

## Criterio de finalización

Existe un ADR por cada decisión principal. Cada uno tiene alternativa descartada y motivo. Relees el ADR tres meses después y aún tiene sentido.

## Después de esta guía

Pasás a P03 sabiendo exactamente por qué cada herramienta está ahí.
