# P08 — Normalización del contenido

**Guía de proyecto · ~2 h**

## Qué construyes

Limpieza de texto sin destruir estructura relevante. Espacios duplicados se eliminan; jerarquía de encabezados sobrevive.

## Contenidos

- Limpieza: espacios, caracteres de control, codificación
- Preservación: encabezados, listas, estructura lógica
- Metadata extraction: capturar encabezados como etiquetas
- Configuración: qué se limpia, qué se preserva

## Criterio de finalización

La jerarquía de encabezados sobrevive. Un fragmento no pierde su contexto por normalización agresiva.

## Después de esta guía

Pasás a P09 con texto limpio y estructurado. Ahora lo fragmentás.
