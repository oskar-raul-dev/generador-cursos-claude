# P20 — Contenedorización con Docker Compose

**Guía de proyecto · ~2 h**

## Qué construyes

JAR de la aplicación. Docker image. docker-compose.yml completo. Alguien clona el repo y con un comando lo levanta.

## Contenidos

- Dockerfile optimizado para Spring Boot
- docker-compose.yml: app + postgres + ollama
- .dockerignore
- Instrucciones en README para reproducibilidad
- Variable de entorno para configuración

## Criterio de finalización

Otro developer clona el repo. `docker compose up` lo levanta. Hace una query. Funciona. Sin intervención manual.

## Después de esta guía

**FIN DE LA PARTE II.** Tienes un RAG completo, funcional, containerizado. Es un punto de parada válido y sistema coherente.

Las Partes III y IV son mejora sobre algo que ya funciona.
