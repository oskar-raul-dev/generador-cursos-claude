# P38 — Prompt injection en documentos

**Guía de proyecto · ~2 h**

## Qué construyes

Defensa en profundidad contra instrucciones maliciosas en documentos.

## Contenidos

- Threat model: documento contiene instrucciones
- Validación: sanitización de entrada
- Grounding fuerte: prompt explícito sobre fuentes
- Test adversario: documento con "ignora instrucciones"

## Criterio de finalización

Documento contiene "ignora las instrucciones anteriores". Sistema no lo ejecuta. Respuesta sigue siendo fundamentada.

## Después de esta guía

Pasás a P39. Ahora información sensible.
