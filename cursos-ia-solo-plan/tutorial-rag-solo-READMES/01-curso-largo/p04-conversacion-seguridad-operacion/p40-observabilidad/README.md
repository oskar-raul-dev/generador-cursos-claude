# P40 — Observabilidad

**Guía de proyecto · ~3 h**

## Qué construyes

Puedes reconstruir qué pasó en una consulta de hace tres días.

## Contenidos

- Query logger: pregunta, recuperación, prompt, respuesta
- Distributed tracing: request ID atraviesa capas
- Métricas: latencia por etapa, tokens, tasa de abstención
- Dashboard: anomalías, tendencias

## Criterio de finalización

Tomas una consulta de ayer. Ves exactamente qué se recuperó, qué se pasó al LLM, qué generó. Todo sin re-ejecutar.

## Después de esta guía

Pasás a P41. Ahora rendimiento y capacidad.
