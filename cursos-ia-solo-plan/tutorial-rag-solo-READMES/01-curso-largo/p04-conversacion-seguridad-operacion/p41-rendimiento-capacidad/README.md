# P41 — Rendimiento y capacidad

**Guía de proyecto · ~2.5 h**

## Qué construyes

Caching, batching, índices vectoriales. Conocés el límite de tu sistema.

## Contenidos

- Query cache: resultados recientes
- Embedding cache: no regenerar lo mismo
- Batch processing: embedding de muchos fragmentos juntos
- Índices: HNSW para búsqueda aproximada
- Load test: ¿cuántas queries concurrentes?

## Criterio de finalización

Sistema aguanta tu carga prevista. Latencia es predecible. Cuello de botella está identificado.

## Después de esta guía

Pasás a P42. Ahora manejo de fallos.
