# P39 — Protección de información sensible

**Guía de proyecto · ~2 h**

## Qué construyes

Clasificación de datos sensibles. Qué se registra, dónde queda, por cuánto tiempo.

## Contenidos

- Clasificación: público, interno, confidencial, secreto
- Masking: reemplaza datos sensibles en logs
- Retención: políticas de borrado por clase
- Auditoría: quién accedió qué y cuándo

## Criterio de finalización

Datos sensibles no aparecen en logs de producción. Políticas de retención se aplican automáticamente.

## Después de esta guía

Pasás a P40. Ahora observabilidad.
