# P33 — RAG conversacional

**Guía de proyecto · ~2.5 h**

## Qué construyes

Resolución de referencias. "¿Y si es desde otro país?" usa el turno anterior para transformarse en una consulta autónoma.

## Contenidos

- ConversationHistory: almacena turnos
- QueryDisambiguator: resuelve referencias
- Contexto: pregunta anterior + nueva pregunta → pregunta completa
- Tests: referencias ambiguas resueltas correctamente

## Criterio de finalización

Una pregunta de seguimiento ambigua se resuelve correctamente. Sistema recuerda contexto previo.

## Después de esta guía

Pasás a P34. Ahora distinguís memoria de conversación de conocimiento documental.
