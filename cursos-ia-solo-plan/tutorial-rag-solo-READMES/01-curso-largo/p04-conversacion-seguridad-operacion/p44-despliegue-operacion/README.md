# P44 — Despliegue y operación

**Guía de proyecto · ~3 h**

## Qué construyes

Procedimiento escrito para todo: ambientes (dev, staging, prod), respaldos, migraciones, reindexación en producción.

## Contenidos

- Playbook de despliegue
- Respaldo automático de PostgreSQL
- Procedimiento de reindexación sin downtime
- Rollback plan
- Checklist de pre-deploy

## Criterio de finalización

Un junior puede ejecutar el playbook. Sistema se deploya sin errores. Si algo falla, existe el rollback.

## Después de esta guía

**FIN DE LA PARTE IV.** Sistema listo para producción. Pasás a la Parte V: evaluación y cierre.
