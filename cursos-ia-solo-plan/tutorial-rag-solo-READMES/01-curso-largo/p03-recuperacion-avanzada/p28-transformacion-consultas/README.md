# P28 — Transformación de consultas

**Guía de proyecto · ~2 h**

## Qué construyes

Query rewriting: "¿cómo pido un día libre?" → "solicitar día feriado". Una pregunta coloquial recupera lo mismo que su versión precisa.

## Contenidos

- QueryRewriter interface
- Usa el LLM para reescribir
- Múltiples reescrituras
- Configuración: cuántas variantes

## Criterio de finalización

Una pregunta coloquial después de rewriting recupera lo mismo que su versión precisa. Hit Rate mejora.

## Después de esta guía

Pasás a P29. Ahora implementás multi-query retrieval.
