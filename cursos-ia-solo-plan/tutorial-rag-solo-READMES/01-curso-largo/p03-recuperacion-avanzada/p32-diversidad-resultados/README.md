# P32 — Diversidad de resultados

**Guía de proyecto · ~2 h**

## Qué construyes

Evitas cinco fragmentos que dicen lo mismo. Maximizás cobertura temática.

## Contenidos

- DiversityRanker interface
- Detección de similitud entre resultados
- Re-ranking: prioriza tema nuevo
- Configuración de diversidad

## Criterio de finalización

Top-K retorna fragmentos de temas distintos. Hit Rate no empeora. Variedad mejora.

## Después de esta guía

**FIN DE LA PARTE III.** Recuperación avanzada completa. Pasás a la Parte IV: conversación, seguridad, operación.
