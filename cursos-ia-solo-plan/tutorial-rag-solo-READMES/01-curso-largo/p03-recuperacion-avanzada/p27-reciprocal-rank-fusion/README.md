# P27 — Reciprocal Rank Fusion

**Guía de proyecto · ~1.5 h**

## Qué construyes

Implementás RRF: fusionas rankings sin normalizar puntajes. Fórmula: RRF(d) = Σ 1/(k+rank(d)).

## Contenidos

- Fórmula de RRF
- Implementación en Java
- Comparación con normalización de puntajes
- Benchmark: RRF vs puntaje normalizado

## Criterio de finalización

RRF implementado. Resultados de P26 mejoran o se mantienen. Entendés por qué RRF es más robusto que normalizar.

## Después de esta guía

Pasás a P28. Ahora implementás query rewriting.
