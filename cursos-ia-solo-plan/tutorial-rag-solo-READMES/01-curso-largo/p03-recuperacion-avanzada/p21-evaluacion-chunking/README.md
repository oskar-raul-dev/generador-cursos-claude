# P21 — Evaluación del chunking

**Guía de proyecto · ~2.5 h**

## Qué construyes

Experimento comparativo: varías chunk_size y overlap. Mides Hit Rate para tus preguntas de P05. Elegís configuración con datos.

## Contenidos

- Dataset de P05 con fragmentos relevantes marcados
- Tabla: chunk_size × overlap → Hit Rate
- Script de evaluación
- Decisión justificada con números

## Criterio de finalización

Elegís configuración de chunking basada en datos, no intuición. Documentás por qué esa configuración ganó.

## Después de esta guía

Pasás a P22 sabiendo exactamente si tu chunking funciona. Si no, lo cambias ahora.
