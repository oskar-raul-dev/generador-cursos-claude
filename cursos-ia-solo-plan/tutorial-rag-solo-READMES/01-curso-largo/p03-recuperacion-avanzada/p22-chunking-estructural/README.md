# P22 — Chunking estructural

**Guía de proyecto · ~2 h**

## Qué construyes

Chunker que respeta encabezados y secciones. Una sección lógica no se parte a mitad de regla.

## Contenidos

- SemanticChunker interface
- MarkdownSemanticChunker: divide por encabezados
- Preservación de jerarquía en metadatos
- Fallback a fixed-size si no hay estructura

## Criterio de finalización

Un documento con secciones se fragmenta respetándolas. Hit Rate mejora o se mantiene. Si empeora, vuelves a P21.

## Después de esta guía

Pasás a P23 con chunking estructural. Ahora agregás filtrado por metadatos.
