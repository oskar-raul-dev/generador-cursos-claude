# P29 — Multi-query retrieval

**Guía de proyecto · ~2 h**

## Qué construyes

Múltiples formulaciones equivalentes de la misma pregunta. Aumentás cobertura.

## Contenidos

- MultiQueryGenerator interface
- Generación de variantes semánticas
- Unión de resultados
- Deduplicación

## Criterio de finalización

Preguntas ambiguas ahora recuperan fragmentos relevantes de múltiples ángulos. Hit Rate mejora.

## Después de esta guía

Pasás a P30. Ahora implementás reranking.
