# P23 — Metadatos y filtros

**Guía de proyecto · ~2 h**

## Qué construyes

Búsqueda filtrada por departamento, versión, idioma. Sin reindexar.

## Contenidos

- Metadata fields en chunk
- Filtro SQL en búsqueda vectorial
- Endpoint `/api/search?question=...&department=...`
- Fallback si no hay resultados con filtro

## Criterio de finalización

Especificás un filtro. Recuperás solo fragmentos que lo cumplen. Sin reindexar. Sin pérdida de velocidad.

## Después de esta guía

Pasás a P24. Ahora implementás parent-child retrieval.
