# P31 — Compresión del contexto

**Guía de proyecto · ~2 h**

## Qué construyes

Eliminas contenido irrelevante antes de construir el prompt. Menos tokens, misma calidad.

## Contenidos

- ContextCompressor interface
- Filtrado: mantener solo lo relevante
- Resumen: condensar sin perder información
- Medición: tokens guardados vs latencia agregada

## Criterio de finalización

Contexto es más compacto. Respuesta es igual de buena. Tokens procesados bajan.

## Después de esta guía

Pasás a P32. Última técnica de recuperación.
