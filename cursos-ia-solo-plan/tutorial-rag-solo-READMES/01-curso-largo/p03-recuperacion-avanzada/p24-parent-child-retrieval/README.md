# P24 — Parent-child retrieval

**Guía de proyecto · ~2.5 h**

## Qué construyes

Recuperas fragmentos pequeños precisos, pero entregas su contexto amplio. El padre es el párrafo; el hijo, la oración.

## Contenidos

- Modelo: parent-child relationship
- Búsqueda en hijos, retorno de padres
- Configuración de tamaños
- Balance: precisión vs contexto

## Criterio de finalización

Recuperación es precisa. El contexto para generar es suficiente. Hit Rate no empeora.

## Después de esta guía

Pasás a P25. Ahora implementás búsqueda textual.
