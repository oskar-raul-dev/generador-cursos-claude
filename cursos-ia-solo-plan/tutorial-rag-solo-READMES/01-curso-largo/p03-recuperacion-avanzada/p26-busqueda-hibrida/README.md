# P25 — Búsqueda híbrida

**Guía de proyecto · ~2.5 h**

## Qué construyes

Ejecutas dense y sparse en paralelo. Fusionas resultados. Sistema soporta modo hybrid.

## Contenidos

- Ejecución paralela de dos búsquedas
- Fusión de rankings
- Endpoint: `/api/search?mode=hybrid`
- Comparación: dense vs sparse vs hybrid en Hit Rate

## Criterio de finalización

Muestrás un caso donde hybrid recupera algo que dense o sparse solos no recuperan. Hit Rate mejora.

## Después de esta guía

Pasás a P27. Ahora implementás RRF explícitamente.
