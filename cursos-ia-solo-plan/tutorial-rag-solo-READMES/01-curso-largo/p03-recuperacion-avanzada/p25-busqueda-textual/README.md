# P25 — Búsqueda textual

**Guía de proyecto · ~2.5 h**

## Qué construyes

Full-Text Search en PostgreSQL. Encuentras códigos y números que el embedding diluy.

## Contenidos

- Configuración de tsvector en pgvector
- Índice GIN o GIST
- Búsqueda: tsquery y ranking
- Métricas: precision y recall de sparse

## Criterio de finalización

Buscas "ISO-27001" y lo encuentras. Benchmarks muestran speedup. Fragmentos encontrados son relevantes.

## Después de esta guía

Pasás a P26. Ahora combinas dense y sparse.
