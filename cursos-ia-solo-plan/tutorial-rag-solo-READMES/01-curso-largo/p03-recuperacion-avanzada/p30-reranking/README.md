# P30 — Reranking

**Guía de proyecto · ~2.5 h**

## Qué construyes

Recuperas 20 candidatos rápidamente. Un modelo más preciso ordena los mejores 5.

## Contenidos

- RerankingService interface
- LLM-based reranker
- Configuración de topK para reranking
- Medición: mejora en Hit Rate vs latencia agregada

## Criterio de finalización

Reordenas candidatos. Top-K mejora. Hit Rate aumenta. Latencia adicional es aceptable.

## Después de esta guía

Pasás a P31. Ahora implementás compresión de contexto.
