# Semana 5 — Sesión 1: Teoría (1.5 h)

## Contenidos

- Grounding: instrucción explícita de responder solo con evidencia
- Citas: enlazar afirmaciones con fragmentos
- Abstención: reconocer falta de evidencia
- Construcción del prompt

## Criterio de finalización

Entendés que el prompt es un artefacto de diseño. Cambios menores cambian el comportamiento.
