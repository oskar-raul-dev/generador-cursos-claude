# Semana 5 — Sesión 2: Laboratorio (1.5 h)

## Experimentos

1. Prompt sin grounding: modelo ve fragmentos, ninguna regla
2. Prompt con grounding: obligación de usar solo la evidencia
3. Prompt con grounding + citas: además, debe citar

Para cada versión:
- Pregunta sobre licencia de maternidad (no en corpus)
- ¿Alucina o se abstiene?

## Criterio de finalización

Demostraste que grounding cambia comportamiento. Con grounding se abstiene; sin grounding, alucina.
