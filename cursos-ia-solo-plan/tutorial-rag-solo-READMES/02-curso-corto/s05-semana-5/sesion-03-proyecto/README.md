# Semana 5 — Sesión 3: Proyecto (2.5 h)

## Qué construyes

ResponseGenerator: prompt formateado + LLM → respuesta con citas.

## Tareas

1. PromptBuilder: instrucciones + fragmentos + pregunta
2. ChatClient: llamada a gemma3:4b
3. CitationExtractor: detecta [Fuente 1], mapea a original
4. Cuatro preguntas de prueba:
   - Responden y citan
   - Licencia de maternidad → abstención

## Criterio de finalización

RAG funcional end-to-end. Respuestas tienen citas verificables. Abstención ocurre cuando debe.
