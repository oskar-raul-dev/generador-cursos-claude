# Semana 2 — Sesión 3: Proyecto (2.5 h)

## Qué construyes

Lectura de TXT y Markdown. Chunking configurable. Volcado a JSON.

## Tareas

1. DocumentReader: lectura de TXT y MD
2. Chunker: split_text integrado
3. Cada chunk: {text, source, position, hash}
4. Output: chunks.json

## Criterio de finalización

Leés archivos desde corpus/. Generás chunks. JSON es inspeccionable. Puedes cambiar chunk_size en config sin recompilar.
