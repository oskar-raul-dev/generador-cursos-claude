# Semana 1 — Sesión 1: Teoría (1.5 h)

## Contenidos

- Problema: LLM locales alucina sin contexto
- Solución: RAG = recuperación + generación
- Dos pipelines: ingestión (una sola vez) y consulta (cada pregunta)
- Por qué "meter todo" no escala: dilución de señal

## Conceptos clave

**Conocimiento paramétrico:** lo que el modelo aprendió durante entrenamiento  
**Alucinación:** respuesta falsa con confianza  
**Ventana de contexto:** límite de tokens que el modelo acepta  
**RAG:** Retrieval-Augmented Generation

## Criterio de finalización

Explicás sin notas por qué "meter todos los documentos en el prompt" no escala. Tu argumento es técnico, no solo "cuesta tokens".
