# Semana 1 — Sesión 2: Laboratorio (1.5 h)

## Experimentos

**Experimento 1:** Preguntá al modelo algo que no sabe (política de vacaciones). Verifica alucinación.

**Experimento 2:** Pegá el documento completo en el prompt. Verifica que ahora responde bien.

**Experimento 3:** Pegá veinte documentos irrelevantes. Observá:
- Latencia aumenta
- Respuesta se vuelve vaga
- Costo aumenta
- El modelo se pierde en el ruido

## Código

Python + ollama. Llamadas simples al LLM. No necesitas vector store todavía.

## Criterio de finalización

Ejecutaste los tres experimentos. Documentaste observaciones. Entendés la relación entre cantidad de contexto y calidad.
