# Fase 3: Machine Learning estadístico

**Duración:** 14–17 semanas | **Horas reales:** ~84–102 h | **Acumulado:** ~12 meses

## Resumen

Fundamentos de ML *antes* de redes neuronales: qué es aprender de datos, sesgo/varianza, regularización, validación. Modelos "clásicos" que siguen siendo el default en industria.

## Temas principales

- Aprendizaje supervisado: regresión, clasificación
- Árboles de decisión, random forests, gradient boosting (XGBoost/LightGBM)
- SVM y kernels
- Aprendizaje no supervisado: k-means, clustering, PCA, reducción de dimensionalidad
- Sesgo-varianza, validación cruzada, regularización (L1/L2)
- Métricas correctas: no solo accuracy (AUC, F1, calibración)
- Ingeniería de características y pipelines reproducibles
- Introducción a causalidad: correlación ≠ causalidad

## Recursos principales

- Andrew Ng, *CS229: Machine Learning* (Stanford)
- James et al., *An Introduction to Statistical Learning* (ISLR)
- Aurélien Géron, *Hands-On Machine Learning* (O'Reilly)

## Proyecto tesis

Predicción de ETA, detección de pedidos de riesgo, pronóstico de demanda con gradient boosting.

## Criterio de salida

Explicas por qué 95% accuracy puede ser inútil; justificas L1 vs L2 matemáticamente.
