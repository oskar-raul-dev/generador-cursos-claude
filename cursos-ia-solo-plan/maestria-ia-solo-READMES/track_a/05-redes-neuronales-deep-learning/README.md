# Fase 5: Redes neuronales y Deep Learning (fundamentos)

**Duración:** 14–17 semanas | **Horas reales:** ~84–102 h | **Acumulado:** ~17.5 meses

## Resumen

Red neuronal desde álgebra hasta código: no caja negra de Keras. Exactamente qué hace cada línea de backpropagation.

## Temas principales

- Perceptrón, MLP, funciones de activación
- Backpropagation: derivación matemática e implementación a mano
- Descenso de gradiente estocástico, momentum, Adam
- Regularización: dropout, batch norm, weight decay
- Introducción a arquitecturas: CNN, RNN/LSTM, Transformers (detalle en Fases 6–7)
- Autograd: cálculo automático de gradientes

## Recursos principales

- Andrej Karpathy, *Neural Networks: Zero to Hero* (YouTube) — backprop, micrograd, GPT desde cero
- MIT 6.S191, *Introduction to Deep Learning*
- Goodfellow, Bengio, Courville, *Deep Learning* (gratuito)
- 3Blue1Brown, serie *Neural Networks*

## Proyecto tesis

Mejora de ETA con red neuronal (embeddings de zona/dirección, features temporales), comparada rigurosamente vs. baseline de gradient boosting.

## Criterio de salida

Programas y explicas backpropagation sin mirar apuntes, para red de ≥2 capas ocultas.
