# Fase 9: Sistemas de IA en producción

**Duración:** 14–17 semanas | **Horas reales:** ~84–102 h | **Acumulado:** ~29 meses

## Resumen

Aquí entran LLMs modernos y agentes — con base de 8 fases anteriores, entendiendo arquitectura, límites, costos, evaluación, despliegue. No solo "prompt engineering de moda".

## Temas principales

- Ciclo de vida de ML en producción: versionado de datos/modelos, monitoreo, drift
- Fine-tuning eficiente (LoRA/QLoRA), cuantización, inferencia eficiente
- Arquitecturas de agentes: planeación, herramientas, memoria
- Evaluación exhaustiva de sistemas basados en LLM
- Seguridad, sesgo, interpretabilidad
- Gobernanza y cumplimiento (Ley de IA UE, auditabilidad)
- Hardware: cuantización, GPU vs. TPU, precisión numérica

## Recursos principales

- *Full Stack Deep Learning* (fullstackdeeplearning.com)
- fast.ai, *Practical Deep Learning for Coders*
- DataTalks.Club, *MLOps Zoomcamp* (gratuito)
- Chip Huyen, *Designing Machine Learning Systems* (O'Reilly)
- Christoph Molnar, *Interpretable Machine Learning* (gratuito)

## Proyecto tesis

Convergencia de Fases 1–8: versionado de modelos, monitoreo de drift, agentes para excepciones, gobernanza sobre decisiones de asignación.

## Criterio de salida

Diseñas (en documento técnico) arquitectura completa de sistema productivo: ingesta, features, entrenamiento, servido, monitoreo — justificando cada decisión.
