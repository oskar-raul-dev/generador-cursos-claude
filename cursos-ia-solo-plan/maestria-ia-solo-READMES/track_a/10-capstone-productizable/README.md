# Fase 10: Capstone productizable + portafolio

**Duración:** 7–12 semanas | **Horas reales:** ~42–72 h | **Acumulado:** ~31–33 meses

## Resumen

Integración final del proyecto tesis (no un capstone nuevo de cero). Pulir e integrar la plataforma logística construida desde Fase 1.

## Componentes

1. **Ingesta y data lake:** pipeline de operación (pedidos, rutas, entregas, inventario, clima, tráfico) en estructura bronze/silver/gold
2. **Feature store / capa analítica:** tendencias de demanda, series temporales por zona/categoría
3. **Integración completa:** motor de ruteo (F1) + ETA/scoring (F3/5) + validación causal (F4) + visión (F6) + soporte conversacional (F7) + despacho dinámico (F8) + gobernanza (F9)
4. **Servido y producto:** API + dashboard mostrando operación, tendencias, predicciones
5. **Documentación tipo case study:** problema, arquitectura, decisiones, resultados, limitaciones

## Portafolio final

- **Capa (a):** mini-proyectos de cada fase, variados en dominio (demuestran técnica aislada)
- **Capa (b):** plataforma logística integrada (demuestra construcción de sistema real y coherente)

Esa combinación es más creíble que certificados bootcamp.

## Criterio de salida

Sistema completo desplegable, documentación honesta (limitaciones incluidas), potencial real de venderse como servicio.
