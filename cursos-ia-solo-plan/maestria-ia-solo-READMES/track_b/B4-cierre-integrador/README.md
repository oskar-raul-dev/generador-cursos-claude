# B4: Cierre integrador — Analizador de tendencias/ventas

**Intensidad:** Final de Fase 0 | **Tiempo:** ~2 h/semana durante Fase 0

## Resumen

Cierre de Pista B: algo pequeño pero real que integre B0–B3 con disciplina, sin "vibe coding" ciego.

## Pasos

1. Define el problema de negocio en una frase (ej. "detectar categorías creciendo/cayendo mes a mes")
2. Usa Claude Code o Codex CLI para acelerar (ingesta, API, visualización) — pero **revisando y entendiendo cada pieza**
3. Decide con criterio: ¿alguna parte se beneficia de modelo local/fine-tuneado (clasificación de reseñas) o es mejor API?
4. Entrega algo demostrable: API + dashboard simple, documentado

## Nota

Este es deliberadamente versión rápida/ligera de ideas que se retoman con más profundidad en capstone Fase 10. Diferencia: velocidad de entrega ahora vs. rigor de producción después.

## Integración B0–B3

- Agentes de código (B0) aceleran construcción
- MCP (B1) expone tus datos/APIs
- Modelos locales (B2) para componentes específicos
- Fine-tuning (B3) si necesitas modelo especializado
