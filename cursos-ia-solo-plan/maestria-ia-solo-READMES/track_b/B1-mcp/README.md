# B1: MCP (Model Context Protocol)

**Intensidad:** Primer tercio de Fase 0 | **Tiempo:** ~2 h/semana durante Fase 0

## Resumen

Estándar abierto para conectar herramientas de IA con fuentes de datos y sistemas externos. Cliente-servidor: agente (cliente MCP) ↔ servidores MCP (CRM, BD, API propia).

## Qué practicar

- Construye tu propio servidor MCP simple exponiendo herramienta o fuente de datos real
- Conéctalo a Claude Code, Codex CLI o Qwen Code
- Verifica end-to-end

## Perspectiva backend

Esto es diseñar una API con contrato específico: no contenido nuevo para developer backend, formato nuevo aplicado a algo que ya sabes hacer.

## Recursos

- Especificación y documentación MCP: modelcontextprotocol.io
- Soportado natively en Claude Code, Codex CLI, Qwen Code
