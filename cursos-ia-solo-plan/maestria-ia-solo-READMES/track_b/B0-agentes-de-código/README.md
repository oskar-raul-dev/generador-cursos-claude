# B0: Agentes de código — Claude Code, Codex CLI, Qwen Code

**Intensidad:** Primer tercio de Fase 0 | **Tiempo:** ~2 h/semana durante Fase 0

## Resumen

Herramientas de codificación agéntica: lee tu código, edita archivos, ejecuta comandos, integra herramientas de desarrollo.

## Qué practicar

- Instala y usa los tres agentes en proyecto real (no "hola mundo")
- Pide implementar funcionalidad completa, corregir bugs, explicar código desconocido
- Entiende el bucle agente: contexto → plan → ejecuta herramientas → verifica → repite
- Compara explícitamente: modos de aprobación, manejo de contexto, cuándo uno falla y otro no
- Contraste: modelo cerrado (Claude/GPT) vs. abierto (Qwen3-Coder) vía API o local
- **Context engineering:** instrucciones claras para que no alucine sobre tu codebase
